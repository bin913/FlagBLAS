# Level 2 Functional and Performance Shape Alignment

## Goal

Ensure the correctness tests for TPSV, TBSV, SYR, and HER include every shape used by their corresponding performance tests.

## Design

Keep the existing test structure and parameterized correctness cases. Expand the functional-test size constants to the ordered union of their existing boundary sizes and the performance-test sizes:

- TPSV: unify `TPSV_SIZES` with the performance `TPSV_SIZES` while retaining existing small and boundary sizes.
- TBSV: unify `STBSV_SIZES` and `STBSV_KS` with the performance `STBSV_SIZES` and `STBSV_KS`, retaining zero and existing boundary sizes.
- SYR: unify `SYR_SIZES` with the performance `SYR_SIZES` while retaining existing sizes.
- HER: unify `HER_SIZES` with the performance `HER_SIZES` while retaining existing sizes.

No new helper module, synchronization assertion, or dedicated smoke-test layer will be introduced. Existing correctness parameterizations will consume the expanded constants directly.

## Scope and Acceptance

The requirement concerns shape coverage only. It does not require every performance shape to be repeated across every possible `uplo`, `trans`, `diag`, `incx`, or `lda` combination beyond the combinations already produced by the existing parameterized tests.

Acceptance is satisfied when each performance size set is a subset of the corresponding functional size set, TBSV performance `(n, k)` pairs are generated by the functional `n` and `k` constants, Python syntax checks pass, and focused test collection succeeds.
